# تاج الوقار

منصة Laravel + Blade لإدارة حلقات تحفيظ القرآن: ملفات الطلاب، جدول اليوم، تسجيل الحصة، نور البيان، ومساعد للشرح.

## التشغيل على ويندوز

1. انقري مرتين على `start.bat`.
2. المتصفح سيفتح على [http://127.0.0.1:8000](http://127.0.0.1:8000).

البيانات تُحفظ في ملف SQLite داخل المشروع (`database/database.sqlite`). لا حاجة لـ MySQL.

توجد بيانات تجريبية لأربعة طلاب وجدول اليوم حتى تجرّبي النظام فوراً.

من الإعدادات يمكن رفع صورة المعلمة وفيديو تعريفي من الجهاز، مع الإيميل وواتساب والدولة.

## التشغيل يدوياً

يحتاج PHP 8.3 أو أحدث مع Composer.

```bash
composer install
copy .env.example .env
php artisan key:generate
php artisan storage:link
php artisan migrate --seed
php artisan serve
```

## ماذا يفعل النظام؟

- **لوحة اليوم:** حصص اليوم بالترتيب، مع المطلوب لكل طالب وزر بدء الحصة.
- **ملف الطالب:** الاسم، رابط Google Meet، آخر موضع، الحفظ، التسميع، المراجعة، والملاحظات.
- **نور البيان:** مهارات العربية والتقدم والأنشطة المقترحة.
- **أثناء الحصة:** تسجيلي سريع لما سُمّع وحُفظ ورُوجع، ثم يُحدَّث ملف الطالب تلقائياً عند الإنهاء.
- **المساعد الذكي:** يجهّز شرحاً مناسباً لمستوى الطالب وأسلوبه. يعمل بدون إنترنت بأسلوب جاهز، أو بمفتاح OpenAI من الإعدادات لشرح أقوى.
