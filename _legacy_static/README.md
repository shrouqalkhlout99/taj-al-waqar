# نظام معلمة القرآن

تطبيق ويب بسيط لإدارة حلقات تحفيظ القرآن: ملفات الطلاب، جدول اليوم، تسجيل الحصة، ومساعد للشرح.

## التشغيل

1. افتحي ملف `index.html` في المتصفح (دابل كلك).
2. أو شغّلي `start.bat`.

البيانات تُحفظ على نفس الجهاز داخل المتصفح. لا حاجة لإنترنت إلا لنص الآية من الإنترنت، أو إذا أضفتِ مفتاح OpenAI من الإعدادات.

توجد بيانات تجريبية لأربعة طلاب وجدول اليوم حتى تجرّبي النظام فوراً.
